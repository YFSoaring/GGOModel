# Genomic Instability and Coordinated Tumor-Margin Immune Ecosystem Remodeling Drive Distinct Dynamic Progression Trajectories in Pulmonary Ground-Glass Nodules

A tumor margin-aware, interpretable radiomics-based machine learning model

This repository contains the radiomics analysis pipeline used to develop a machine-learning model for predicting the future progression pattern of pulmonary ground-glass nodules (GGNs) from baseline CT images.

The pipeline includes:

1. Intra-nodular and peri-nodular radiomic feature extraction
2. Two-stage radiomic feature selection
3. Feature normalization
4. Extra Trees classifier construction
5. Model evaluation in training, internal testing, and external testing datasets
6. Python 3.7.16 PyRadiomics 3.0.1
